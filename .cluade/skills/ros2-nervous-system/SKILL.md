# ROS 2 Robotic Nervous System

## When to Use This Skill
- Multi-component robot requiring coordination
- Nodes for perception, planning, and control
- Integration of ROS 2 with Python agents

## How This Skill Works
1. Define ROS 2 nodes and topics
2. Create service/action interfaces
3. Connect perception and control
4. Test communication with simulated robot

## Output Format
- ROS 2 package with nodes, launch files, and topics
- Working message passing between sensors and actuators

## Example
*Input*: Node for reading IMU data  
*Output*: Topic publishing orientation data to control node
