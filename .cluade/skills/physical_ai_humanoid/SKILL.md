# Physical AI Foundations

## When to Use This Skill
- Designing AI that moves and senses in the real world
- Understanding embodiment and physical constraints
- Preparing robots for real-world interaction

## How This Skill Works
1. Study physical laws affecting robots
2. Map perception to action
3. Design sensorimotor loops
4. Prepare sim-to-real pipelines

## Output Format
- Conceptual framework of robot behavior
- Sensor-to-actuator workflow diagram
- Embodied intelligence design notes

## Example
*Input*: Task: “Pick up an object in a room”  
*Output*: Robot design includes camera and IMU data, motion planning loop, and grasping control.
