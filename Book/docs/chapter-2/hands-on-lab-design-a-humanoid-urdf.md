# 2.7 Hands-On Lab: Design a Humanoid URDF

**Content Type:** hands-on project
**Estimated Length:** 10-12 pages

## Description

- Guided project: create a simplified humanoid URDF
- Tasks:
  * Design kinematic chain: base → torso → upper_arm → lower_arm → hand
  * Add visual meshes (simplified primitives: cylinders for limbs)
  * Add collision geometry (overlapping boxes for faster collision checks)
  * Add inertia properties (mass, inertia tensor)
  * Validate URDF syntax
  * Visualize in RViz
  * Compute forward kinematics to a specific joint configuration

- humanoid_simplified.urdf
- RViz config
- Screenshots showing visualization
- Analysis document
