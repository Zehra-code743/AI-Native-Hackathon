# 2.3 Debugging ROS 2 Systems

**Content Type:** technical + hands-on
**Estimated Length:** 10-12 pages

## Description

- ROS 2 command-line tools: ros2 node, ros2 topic, ros2 service, ros2 action
- ros2 topic list / echo / hz / bw (bandwidth monitoring)
- ros2 service list / call
- ros2 action list / send_goal
- Graph visualization: rqt_graph (computation graph)
- Message inspection: rqt_topic
- Bag recording: ros2 bag record/play (replay sensor data)
- Logging and rosout: capturing node output
- Common issues and troubleshooting:
  * Node won't start (missing dependencies, YAML syntax errors)
  * No data on topic (publisher not publishing, QoS mismatch)
  * Service calls timeout (server crashed, network latency)
  * Memory leaks in long-running systems
